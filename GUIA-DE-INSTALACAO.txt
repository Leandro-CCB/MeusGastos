MeuGasto Pro — Guia de Instalação e Hospedagem
================================================

O QUE VOCÊ RECEBEU
------------------
1. MeuGasto-Pro-site-pronto.zip  → o app JÁ COMPILADO e pronto para hospedar (recomendado)
2. MeuGasto-Pro-codigo-fonte.zip → o código-fonte completo, para editar ou publicar na Vercel
3. Este guia


OPÇÃO 1 — HOSPEDAR O SITE PRONTO (mais fácil, funciona em qualquer hospedagem)
------------------------------------------------------------------------------
O app é 100% autônomo: não precisa de servidor Node, banco de dados nem configuração.

a) Hospedagem comum (Hostinger, GoDaddy, cPanel, Plesk, etc.)
   1. Extraia o zip "MeuGasto-Pro-site-pronto.zip" no seu computador
   2. Abra o Gerenciador de Arquivos do seu painel e entre na pasta pública do
      domínio (normalmente "public_html", "www" ou "htdocs")
   3. Envie TODOS os arquivos e pastas que estavam dentro do zip
      (index.html, pasta _next, ícones, manifest.json etc.)
      Dica: também funciona enviar o zip pela pasta e extrair lá dentro
   4. Acesse seu domínio no navegador — o app já está no ar

b) Netlify Drop (grátis, em 30 segundos)
   1. Acesse https://app.netlify.com/drop
   2. Arraste a pasta extraída do zip para a página
   3. Pronto — a Netlify gera um link (depois você pode ligar seu próprio domínio)

c) Vercel (grátis)
   1. Acesse vercel.com e crie uma conta
   2. Siga a Opção 2 abaixo com o código-fonte

IMPORTANTE SOBRE O ENDEREÇO
- Publique na RAIZ do domínio ou subdomínio (ex.: seusite.com ou app.seusite.com)
- Se precisar instalar numa SUBPASTA (ex.: seusite.com/app), me avise antes que
  eu ajusto os caminhos internos para você


OPÇÃO 2 — PUBLICAR PELA VERCEL COM O CÓDIGO-FONTE (bom para atualizar sempre)
------------------------------------------------------------------------------
1. Crie uma conta grátis na vercel.com e no github.com
2. Extraia o zip "MeuGasto-Pro-codigo-fonte.zip"
3. Crie um repositório no GitHub e envie a pasta inteira
   (sem node_modules e sem .next — eles são gerados sozinhos)
4. Na Vercel: "Add New..." → "Project" → selecione o repositório → "Deploy"
5. A Vercel compila sozinha e gera o link de produção

Rodar no seu computador (opcional, para desenvolvimento/testes):
- Instale o Node.js 20 ou superior (https://nodejs.org)
- Na pasta do projeto: npm install   →   npm run dev
- Abra http://localhost:3000


LICENÇAS / SUPABASE — NADA MUDOU PARA SEUS CLIENTES
----------------------------------------------------
- O app já está conectado ao MESMO projeto Supabase do app original
  (códigos de ativação, painel master e validação funcionam como antes)
- Clientes que já ativaram o app antigo no mesmo domínio continuam ativados,
  sem precisar digitar o código de novo (mesmas chaves e mesmo ID de aparelho)
- A aba "Códigos" (painel master) permite criar, editar, revogar, reativar
  códigos e liberar aparelho, igual ao app original
- Se um dia quiser usar outro projeto Supabase, basta definir as variáveis
  NEXT_PUBLIC_SUPABASE_URL e NEXT_PUBLIC_SUPABASE_ANON_KEY (Vercel: Project
  Settings → Environment Variables; na hospedagem comum não é preciso)


DADOS DOS CLIENTES — PROTEÇÃO TOTAL
------------------------------------
- Na primeira visita ao app novo, os dados do app original são importados
  automaticamente do localStorage (lançamentos, receitas, cartões,
  investimentos, contas fixas e compras parceladas antigas)
- ANTES de importar, o app cria automaticamente:
  1. uma cópia de segurança imutável dos dados originais
  2. um registro da migração com data e quantidades
- Nada é apagado: as chaves do app original continuam intactas
- Em Ajustes → "Dados do app original" o cliente pode baixar a cópia de
  segurança (.json) ou restaurar os dados do app antigo a qualquer momento
- Os dados de cada cliente ficam salvos no próprio navegador dele — atualizar
  os arquivos do site NUNCA apaga os dados


ATUALIZAÇÕES FUTURAS
--------------------
- Site pronto: gere/atualize os arquivos e reenvie por cima na hospedagem
- Vercel: faça push no GitHub e a Vercel publica sozinha
- Os dados dos clientes permanecem intactos em qualquer atualização


RESUMO TÉCNICO
--------------
- App: MeuGasto Pro (Next.js 16 + React 19 + Tailwind 4 + shadcn/ui)
- Armazenamento: localStorage do navegador (mesmo modelo do app original)
- Licenças: Supabase RPC (validar_licenca), mesmo banco do app original
- Backup PDF/JSON: compatível com os backups do app original
